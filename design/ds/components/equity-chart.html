Equity chart

The performance curve under the portfolio hero. One responsive inline SVG redrawn on every refresh, period change, SPY toggle and resize. Everything below is the real geometry: viewBox height 310, padding {l:6, r:66, t:16, b:10}, width = the container's clientWidth floored at 320. Where the source writes a token into an SVG presentation attribute (stroke="var(--pos)", font-family="var(--mono)") the specimens carry the expanded literal, so a specimen never depends on custom-property substitution inside attributes.

Direction rule — the only colour decision in the chart

upAll = ai[ai.length-1].v >= ai[0].v — last visible point vs first visible point, not profit-vs-cost. return_pct is rebased by the API to the first point of the window, so ai[0].v is always 0 and the test is "did this window end above where it started". One boolean drives the stroke, the gradient, the end label and the scrub dot. Everything else in the chart is neutral.

Scrub — crosshair, dots, tooltip, and the hero rewrite

A transparent <rect id="hz"> (x = P.l, width = W−P.l−P.r, full height, cursor:crosshair) captures pointermove / pointerdown. The nearest index is rounded from the pointer x, then the hero figure, the hero delta and the hero date are overwritten with that day's values — Robinhood-style. pointerleave / pointerup restore the live snapshot and hide the crosshair. Mobile variant — a different chart, not a port

src/components/EquityChart.tsx ships no chart library: it draws plain RN <View>s so it can go out over-the-air on any installed build. Nothing from the web chart survives — no line, no gradient, no glow, no zero line, no scrub, no tooltip. Instead: opacity-.45 equity bars, dotted SPY markers, an α chip, and a drawdown ribbon that the web has no equivalent of. Rendered here at a 375pt viewport (chartW = width − 48 = 327) with a 32-point history.

Not in the source

For the avoidance of invention: drawChart() has no y-axis ticks, no x-axis date ruler, no gridlines, no hover state distinct from scrub, no keyboard scrub (the #hz rect is pointer-only and not focusable), no animated period transition (a tab click sets DRAWN=true, so the draw-in never repeats), no error state of its own (fetch errors surface in #err above the hero), and no light theme — :root declares color-scheme:dark and there is no prefers-color-scheme block anywhere in the file. The mobile component has no loading state either; the screen above it swaps the whole subtree.
