Deviations from source in this card

Everything above is source-exact except these two, changed only so the specimen renders standalone: .card source is `…border-radius:16px;margin-top:16px`. The margin is dropped — this card shows one card, not a stack, and the 16px would read as a spec of the row. .card>.hd h3 source selector is `.card>.hd h2`, and the product markup is `<h2 data-i18n="pos_h">Pozisyonlar</h2>`. Retargeted to h3 (both selector and specimen markup) because h2 is this documentation file's section heading. Every declared value is unchanged: 12px / 650 · letter-spacing .1em · --ink2 · uppercase. The `body` rule keeps the product's typography but swaps the product's `overflow-x:hidden` for the documentation frame's fixed `width:900px;padding:28px 24px 40px`.
This component has no icons in either implementation — the web avatar is text (ticker.slice(0,4)), the mobile affordance is the literal string "Analiz →". Nothing here was drawn that the source does not draw.
