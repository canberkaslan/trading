Foundations

Colour

Two palettes ship in TRADER and they are not the same system. The web dashboard defines seventeen CSS custom properties on :root in agent/api/static/dashboard.html — fifteen colours plus two font stacks; the mobile app exports thirteen constants from mobile/app/src/theme/colors.ts. Both are dark-only: the dashboard declares color-scheme:dark and has no prefers-color-scheme branch, and the mobile app never calls useColorScheme. Every value below is copied from those two files.

Surfaces

Both muted greys were raised — only one of them is guarded

The comment in colors.ts is a record of the mobile fix:

// WCAG AA (4.5:1) on all app backgrounds — #666 was 3.4:1 (fail).
// #949494 → 5.0:1 on the lightest surface (#262626), 6.5:1 on #0a0a0a,
// still visibly dimmer than textSecondary. Guarded by utils/contrast.test.ts.

That guard is real. src/utils/contrast.test.ts asserts every text token against all three mobile backgrounds, keeps a regression case meetsAA('#666666', colors.background) === false, and walks app/ and src/components/ for screens that hard-code color: '#555' or '#666'.

The web dashboard has since had the same fix applied by hand: --ink3 moved from #5d6673 (3.39:1 on --bg) to #828b9a, which clears AA on all four web surfaces — the tightest being 4.75:1 on --s3. What web still lacks is the guard: there is no contrast test on the web side, so nothing stops the next tweak from walking the value back down.

There is no third state to show here, because nothing consumes these tokens. upCB and downCB appear in colors.ts and nowhere else in mobile/app/src or mobile/app/app — no toggle in settings.tsx, no preference in storage, no branch in EquityChart. Resolved — the disclaimer grey

Seven mobile screens once styled the legal disclaimer color: '#555', at 2.66:1 on background — below the bar textMuted had been raised to clear, on the one line of those screens that most needs to be read. All seven now use colors.textMuted, and contrast.test.ts walks the screen files so the literal cannot come back under that property name.
