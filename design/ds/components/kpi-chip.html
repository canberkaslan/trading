Value tone — the only three

The third argument of chip(k,v,c,s) is a class name placed on .v: 'up', 'down', or the empty string. Empty is a real, deliberate state — the value keeps body ink and nothing on the chip is coloured. (An empty class leaves class="v mono " with a trailing space; harmless, but that is what ships.)

Two different minus glyphs ship in this one row, and they are not interchangeable. sgn(v,d) = (v>0?'+':v<0?'−':'')+Math.abs(v).toFixed(d) → U+2212 MINUS SIGN for negatives, ASCII + for positives, no sign at all for exact zero; pct() is sgn()+'%', so the Bugün sub and the Alpha value carry U+2212. The Bugün value builds its own sign from the same U+2212 literal (L473). Sharpe and Maks. düşüş do not go through sgn() — a bare toFixed() emits ASCII HYPHEN-MINUS. Both specimens above are set with the glyph the code actually produces; keep them apart. usd(v) = '$' + Math.round(v).toLocaleString('en-US') — no cents anywhere in a chip. max_dd_pct arrives negative from the API (sc.max_dd is a negative magnitude), so the drawdown chip reads -4.2% against a positive-magnitude gate of 15%.

Entrance

Applied to the row, not the chip. .chips.rise.d3 — opacity 0 → 1, translateY(14px) → 0, .55s cubic-bezier(.2,.7,.3,1) forwards, delay .2s, suppressed entirely under prefers-reduced-motion: reduce (.rise{animation:none;opacity:1;transform:none}), which also kills the .15s hover transitions (*{transition:none!important}) — the 1px lift still happens on hover, it just happens instantly. Individual chips never stagger.

What in this card is not the source

Everything under “the component, verbatim” is byte-identical to dashboard.html L99–L105, and the :root block to L11–L20. Two things are not: the body rule, which drops overflow-x:hidden and adds a fixed 860px sheet so specimens have a page to sit on, and .chip.is-hover, which exists only to freeze the hover specimen — it repeats the declarations of .chip:hover and adds nothing. Numbers in the specimens are illustrative but internally consistent with one book of roughly $109k equity; the formats, gates, glyphs and locale strings are the real ones.
